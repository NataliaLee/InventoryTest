# InventoryTest

Управление: на первом экране задается вместимость инвентаря (ограничена 16 изза верстки)

На втором экране слева можно добавлять предметы в инвентарь выбирая их из выпадающего списка и задавая колво.

Справа находится инвентарь. При двойном тапе можно открыть сундуки. При единичном тапе можно перемещать предмет в другую ячейку.

Чтобы удалить предмет: выберите предмет и нажмите remove.

Кнопка Undo работает на 3 последних действия. Можно увеличить колво сохранений на сцене в Bootstrap объекте.

InventoryLogic

Все объекты имеют тип Item. У стакающихся объектов должен быть реализован интерфейс IStackable. Сделано через интерфейс чтобы предметы могли реализовывать и другие интерфейсы описывающие их возможности (IEquipable).

Есть отдельный тип предмета ContainerItem - он не IStackable.

InventoryState - хранит текущее состояние инвентаря. Любую операцию над инвентарем мы проводим над клоном состояния, чтобы при неудачном результате состояние не изменялось.
